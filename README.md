# ShopAppBackEnd

## Description
This is the backend for the ShopApp, providing API endpoints for product management, user authentication, image uploads, and more.

## Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/IDAN2468D/ShopAppBackEnd.git
   ```
2. Navigate to the project directory:
   ```bash
   cd ShopAppBackEnd
   ```
3. Install dependencies:
   ```bash
   npm install
   ```

## Usage

1. Set up environment variables in a `.env` file (see `.env.example` for reference).
2. Start the server:
   ```bash
   npm start
   ```

## Technologies

- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT for authentication
- Cloudinary for image storage
- Redis for caching (optional)
